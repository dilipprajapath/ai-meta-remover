# AI Metadata Remover — Python dependencies

# NOTE FOR BUILDING THE .EXE:
#   You do NOT install these yourself. The build script (build.bat /
#   build_installer.bat) creates a temporary virtual environment, installs
#   exactly the versions below, and calls PyInstaller. This keeps the final
#   single-file .exe free of any leftover runtime dependencies.
#
#   PyInstaller is installed in the build venv too (see scripts/build.bat).
# ---------------------------------------------------------------------------

# Pillow = image decode/encode + the ORIGINAL (harmless) JPEG/PNG EXIF
# profiles. We deliberately pin an older major so the lossless custom-APPn
# restripping path in jpeg_clean.py stays deterministic. Pillow never
# *creates* an APPn marker for PNG or plain (non-JFIF) JPEG chunks, so all
# original bytes survive byte-for-byte.
#
# The exact version depends on the Python that runs the build
# (pip "environment markers" pick it automatically):
#   * Python 3.9 - 3.12  -> Pillow 10.4.0  (fully deterministic build)
#   * Python 3.13 and 3.14 -> Pillow 12.x  (10.4.0 predates those Pythons
#                             and has no wheels; engine is tested green on
#                             Pillow 12.3.0 as well)
Pillow==10.4.0; python_version < "3.13"
Pillow>=12.0,<13.0; python_version >= "3.13"

# piexif = surgical removal of EXIF / XMP / thumbnail APP1 chunks from JPEG.
piexif==1.1.3

# defusedxml — lets Pillow surface XMP packets during the pre-scan report
# (without it Pillow warns and skips XMP). Removal itself never depends on it.
defusedxml==0.7.1

# Flask = the tiny built-in web server (run entirely on 127.0.0.1).
Flask==3.0.3

# PyInstaller — used ONLY at build time inside the temporary venv, never at
# runtime. Pinned per Python version (your machine runs 3.14, which needs
# PyInstaller 6.15+ — 6.10.0 only supports Python < 3.14):
#   * Python 3.9 - 3.13 -> 6.10.0
#   * Python 3.14+     -> latest 6.15+ release
pyinstaller==6.10.0; python_version < "3.14"
pyinstaller>=6.15,<7; python_version >= "3.14"

# pyinstaller-hooks-contrib — pulls in Flask's hidden data files so the
# packaged one-file exe finds its templates/static folders. Requires-python
# is >=3.8 with no upper bound, so a single pin covers every version above.
pyinstaller-hooks-contrib>=2024.8

# ---------------------------------------------------------------------------
# Native desktop window (Edge WebView2 via pywebview).
# ---------------------------------------------------------------------------
pywebview>=5.3,<7; sys_platform == "win32"
